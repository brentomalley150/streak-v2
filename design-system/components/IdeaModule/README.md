# IdeaModule
A titled panel, used most for today's ideas: one block per activity, two ideas each.

**Markup:** `<div class="mod">` with `<div class="head">` (uppercase `micro`, `muted`) then rows of `<div class="idea">` holding `.idea-h` (icon and activity), optional `.idea-focus` (`green-text`) and `.idea-t` lines.

- The head names the theme: "Today's ideas · Space".
- Ideas are suggestions; never imply the activity needs one.
- Shown for today only, not when logging a past day.
