# ProjectionRange
The optional fall estimate: a score range in big figures, labelled as an estimate.

**Markup:** inside a `.mod`, `.proj-range` (h1 size, tabular figures) with "Keep this pace" under it, then "Complete every remaining day: …" with the pace and day count, then the estimate label in `muted`. When off, show only "Off. Nothing about the fall is shown anywhere — here, in emails, or to your kid."

- Parent-only and off until turned on. Never shown to a kid or anyone in a challenge.
- Always a range (about ±3 RIT), always "Estimate based on activity pace — not a test result".
