# Field
A labelled text or number input.

**Markup:** `<label class="field" for="id"><span>Label</span><input class="input" id="id"></label>`.

- Label in `caption` weight 700, `muted`. Input 48px tall, 2px `border`, focus turns the border `purple`.
- Placeholders show an example, never the instruction: "e.g. Declan", "e.g. 185".
- The input's border is decorative (1.19:1 parent); the label and the focus border carry the meaning.
