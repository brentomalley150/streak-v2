# OptionCard
A large tappable choice — a track in onboarding, or a theme or instrument in a 3-column grid.

**Markup:** `<button class="opt" aria-pressed>` with `<span class="ico">` and `<span><span class="t">Title</span><span class="d">Detail</span></span>`. For themes and instruments add `opt--theme` (icon over label) inside `<div class="grid3">`.

- Selected: `green` border on `panel-alt` — chosen, not merely focused.
- Themes and instruments fill the 3-column grid evenly: nine themes make a 3×3.
- The kid picks the theme ("Hand them the phone for this one"); keep the copy at kid reading level.
