# PerfectDayBar
The goal bar under the tiles: do every activity for a +2 bonus, with a live count.

**Markup:** `<div class="perfect">` with `.perfect-star` (🌟), the text in a growing span, and `.perfect-count` ("2/3"). Add `perfect--won` once earned.

- Before: dashed `border`, `soft` text — "Perfect day bonus: do all three for +2 more".
- Won: solid `gold` border, `gold-text` copy — "Perfect day! +2 bonus points".
- Chores all ticked but unconfirmed: "All done — +2 bonus once a grown-up checks".
