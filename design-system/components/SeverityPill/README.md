# SeverityPill
The tone marker on the parent's weekly summary: celebrate, nudge or attention.

**Markup:** `<span class="sev sev--celebrate|sev--nudge|sev--attention">` with an emoji and a word.

- `celebrate` = `green-text`, `nudge` = `purple`, `attention` = `gold-text`, all on `panel-alt` (5.00, 6.41 and 4.58:1 on the parent surface).
- Never shaming. A day in progress isn't a lapse; describe, don't scold.
